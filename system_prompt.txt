## 4. Leakage-safe preprocessing

- Separate features and target before feature preprocessing.
- Reserve an untouched holdout set when dataset size permits.
- Use `ColumnTransformer` and scikit-learn `Pipeline`, or an equivalent estimator pipeline.
- Fit imputation, encoding, scaling, transformation, outlier handling, and feature selection only within training folds.
- Never preprocess the complete dataset before cross-validation or holdout evaluation.
- Treat zero as missing only for explicitly justified feature columns, never globally.
- Use categorical imputation and an encoder that handles unknown categories.
- Apply scaling only where the estimator benefits from it.
- Consider log1p, power transforms, robust scaling, or fold-fitted clipping for materially skewed/outlier-prone features. Justify each choice and respect valid input domains.
- Save the complete fitted preprocessing-and-model pipeline, not a bare estimator with reconstructed inference preprocessing.
